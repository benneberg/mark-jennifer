# Historical variants / prototypes

Nothing in this folder is imported by the app or built by Vite. It is kept only
as a design record so earlier explorations are not lost.

- `Linda-PRD.md`, `PRD-g.md`, `lena-PRD.md` — three byte-identical copies of the
  same early PRD draft. `docs/PRD.md` is the current document; treat these as
  superseded.
- `index.html`, `index2.html`, `lena-and-mark-v2.html`, `lena-campaign-app.html`
  — standalone HTML prototypes from before the React build.

If you need to shrink the repository, this folder can be deleted outright; it
contains no runtime code. (The AI Studio paste dumps that used to live in
`public/assets/aistudio/` were removed for the same reason — they were being
published to the live site.)
